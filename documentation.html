💡 Usage Examples

See how Friday AI can help you in real development scenarios.

Example 1: Code Review

Friday AI: "Review this Python code for security issues"
Code: 
def calculate_average(numbers):
    return sum(numbers) / len(numbers)

Friday AI: "I've identified 3 potential security issues:
1. Potential division by zero if numbers is empty
2. No input validation
3. Missing error handling

Here's the fixed version:
def calculate_average(numbers):
    if not numbers:
        return 0.0
    return sum(numbers) / len(numbers)

Example 2: Test Generation

Friday AI: "Generate unit tests for this function"
Code:
def calculate_discount(price, percentage):
    return price * (1 - percentage / 100)

Friday AI: "Here are comprehensive unit tests:
import unittest

class TestCalculateDiscount(unittest.TestCase):
    def test_normal_discount(self):
        self.assertEqual(calculate_discount(100, 10), 90.0)
    def test_zero_discount(self):
        self.assertEqual(calculate_discount(100, 0), 100.0)
    def test_max_discount(self):
        self.assertEqual(calculate_discount(100, 100), 0.0)
    def test_fractional_discount(self):
        self.assertAlmostEqual(calculate_discount(100, 25), 75.0)
